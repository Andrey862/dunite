# dunite

[English](README.en.md)

> **Авторство.** Проект полностью написан ИИ — vibe coding с моделью
> MiMo-V2.6 Pro в [opencode](https://opencode.ai). Стоимость разработки:
> **$4.65** (openrouter).

Высокопроизводительный клон Obsidian на Rust + [gpui](https://gpui.rs)
(UI-фреймворк Zed IDE). Без Electron, без веб-технологий.

Спецификация и roadmap: [SPEC.md](SPEC.md). Инструкция для агентов и
контрибьюторов: [AGENTS.md](AGENTS.md).

## Возможности

- Live Preview markdown-редактор (исходник обратим, рендер — WYSIWYG)
- Дерево файлов, табы
- Теги, обратные ссылки, изображения
- Полнотекстовый поиск по хранилищу
- Git-бэкапы: автоснапшоты, история, восстановление

Статус: **M0–M6 завершены** (roadmap — §16 SPEC.md).

## Сборка и запуск

```sh
scripts/build-release.sh              # релизная сборка (LTO thin, strip)
./target/release/dunite [хранилище]   # запуск; без аргумента — текущая папка
```

Флаги: `dunite --version`, `dunite --help`.

**Требования:** Linux (Wayland/X11), GPU с поддержкой Vulkan, `git`
(для бэкапов и синхронизации). Шрифты — системные.

Тестовое хранилище: `testdata/vault-small` (собранные edge-cases —
`ignored/testdata/vault-small/edge-cases`, если развернуть плейграунд).

Проверка качества: `cargo test` (юнит + e2e), `cargo bench` (ядро),
`scripts/bench_runtime.sh 10000` (бюджеты §13, см. docs/BENCH.md).

## Руководство пользователя

**Интерфейс.** Слева — дерево файлов (контекстное меню: создать заметку/папку,
переименовать, переместить, копировать/вырезать/вставить, удалить; файлы
перетаскиваются мышью). В центре — табы и редактор. Справа — «Содержание»,
«Обратные ссылки», «Теги» и «История (git)». Внизу — статус-бар: позиция
курсора и сообщения о действиях.

**Общие клавиши:**

| Клавиши | Действие |
|---|---|
| `Ctrl+P` | быстрый переход к заметке |
| `Ctrl+Shift+F` | поиск по хранилищу |
| `F2` | переименовать заметку (ссылки на неё обновятся) |
| `Ctrl+S` | сохранить и снять git-снапшот |
| `F5` | перечитать с диска (правки вне dunite) |
| `Ctrl+G` | создать git-репозиторий в хранилище |
| `Ctrl+W` | закрыть вкладку |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | следующая / предыдущая вкладка |
| `Alt+←` / `Alt+→` | назад / вперёд по истории переходов |
| `Ctrl+Q` | выход |

**Редактор:**

| Клавиши | Действие |
|---|---|
| `←` `→` `↑` `↓`, `Home`/`End`, `PgUp`/`PgDn` | движение курсора |
| `Ctrl+←` / `Ctrl+→` | движение по словам |
| `Ctrl+Home` / `Ctrl+End` | в начало / конец документа |
| `Shift+…` | расширение выделения |
| `Ctrl+A` / `Esc` | выделить всё / снять выделение |
| `Ctrl+Z` | отменить |
| `Ctrl+Shift+Z` или `Ctrl+Y` | вернуть |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | копировать / вырезать / вставить |
| `Tab` | отступ |

В палитре (`Ctrl+P`, `Ctrl+Shift+F`): `Enter` — открыть, `Esc` — закрыть,
`↑`/`↓` — выбор результата.

**Живой предпросмотр.** Маркеры разметки (`#`, `**`, `>`…) скрыты, пока курсор
вне блока; выделение или клик раскрывают исходник. `[[Ссылки]]` рендерятся без
скобок, `#теги` и код подсвечиваются, картинки (`![[файл.png]]`, `![](путь)`)
показываются прямо в тексте. `Enter` в списках и цитатах продолжает пункт.

**Поиск.** Подстрочные совпадения; «фраза в кавычках» — точное совпадение
фразы; выдача — топ-50 со сниппетами, `Enter` открывает заметку.

**Теги и ссылки.** Правая панель: содержание (клик — переход к заголовку),
обратные ссылки (клик — открыть заметку), неразрешённые ссылки, теги
(клик — заметки с этим тегом).

**Git-бэкапы.** Автоснапшоты создаются после изменений; вручную — `Ctrl+S`
или кнопка «снапшот». В «Истории (git)»: область «Заметка»/«Всё», у коммита —
diff-превью и «восстановить …» (всегда новым коммитом). Кнопки `pull`/`push` —
синхронизация через git CLI с вашими учётными данными (`pull` — только
fast-forward); `+ remote` — подключение удалённого репозитория.

**Внешние правки.** dunite следит за файлами хранилища и подхватывает
изменения извне в открытых вкладках; `F5` — принудительное перечитывание.

## Известные ограничения

- сплиты центральной панели — задача после MVP (код в истории git);
- SVG и PDF не рендерятся (SVG — вне MVP, PDF — отдельная задача);
- экспорт в HTML/PDF — вне MVP;
- поиск без стемминга (подстрочные совпадения, как в Obsidian);
- индексация хранилища — на старте (~0.9 с на 10k), не в фоне.

## Структура

Cargo workspace, границы слоёв — SPEC.md §6:

- `crates/dunite-app` — точка входа, wiring подсистем
- `crates/dunite-ui` — компоненты gpui
- `crates/dunite-editor` — текстовый движок (ropey)
- `crates/dunite-markdown` — парсинг markdown
- `crates/dunite-vault` — модель хранилища
- `crates/dunite-index` — граф ссылок и поиск (M3/M4)
- `crates/dunite-git` — git-бэкапы (M5)
- `crates/dunite-settings` — настройки и темы
